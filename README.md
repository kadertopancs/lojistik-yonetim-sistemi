# Logistics Management System

A desktop application for managing vehicle records and fleet capacity, developed with C# and WPF.

## Overview

The Logistics Management System is a portfolio project focused on digitizing logistics operations through a desktop application. The project is being developed incrementally, with an emphasis on data validation, maintainable code, and practical business workflows.

## Technologies

- C#
- .NET
- Windows Presentation Foundation (WPF)
- SQL Server — planned integration

## Current Features

- Add vehicle records
- Validate vehicle information
- Prevent duplicate license plates
- Display registered and active vehicle counts
- Calculate total fleet capacity

## Planned Features

- SQL Server database integration for persistent storage
- Vehicle and trailer management
- Driver and shipment management
- Trip tracking
- Operational reports and dashboard analytics

## Project Status

**In development.** The current version includes a working WPF vehicle management interface. Database integration and additional logistics modules are planned for future iterations.

## Purpose

This project is part of my ongoing software engineering portfolio, demonstrating practical C# desktop development and the gradual implementation of logistics management workflows.
